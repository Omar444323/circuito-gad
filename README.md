# circuito-gad

Simulación empresarial de 1.º GAD: circuito documental, banco simulado y almacén a PMP.

Fases: 1 Base (hecha), 2 Circuito documental y banco (hecha), 3 Almacén con PMP y correo entre empresas (hecha), ajustes a las normas: presupuestos, circulares, cuentas del Estado, pago automático y autorizaciones (en revisión), 4 Profesora, archivo y exportación, 5 Endurecimiento.

Tests: npm test. Decisiones: docs/decisiones.md.
