# circuito-gad

Simulación empresarial de 1.º GAD: circuito documental, banco simulado y almacén a PMP.

Fases: 1 Base, 2 Circuito documental y banco, 3 Almacén con PMP y correo entre empresas, ajustes a las normas (presupuestos, circulares, cuentas del Estado, pago automático y autorizaciones), deudas y rappel por volumen, resto de las normas (protocolo del punto 12, nóminas, IVA, fianzas, cuotas y consumidores), 4 Archivo, exportación, avisos e importador, 5 Endurecimiento.

Tests: npm test. Decisiones: docs/decisiones.md. Copias de seguridad: docs/copias-de-seguridad.md.
